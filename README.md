# Calculadora IMC - React Native

Aplicativo simples desenvolvido em aula para calcular o Índice de Massa Corporal (IMC).

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript

## Funcionalidade

O usuário insere:
- peso
- altura

O aplicativo calcula o IMC e mostra a classificação:

- Abaixo do peso
- Peso normal
- Sobrepeso
- Obesidade

## Como executar o projeto

1. Instalar as dependências
 
```bash
npm install
```

2. Iniciar o projeto
```bash
npx expo start
```

3. Abrir no emulador Android ou no aplicativo Expo Go.
